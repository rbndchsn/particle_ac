# Why this exists

Fourteen documents translated independently will drift. If the same concept is
rendered three ways across the archive, a francophone physicist reads it as amateur
work, and that costs more credibility than leaving the text in English. These choices
are binding. Where a term is genuinely contested, the reasoning is given.

# Conventions

- **Numbers.** Decimal comma, thin space for thousands: 13 000, 0,8 %, 15,3 G CHF.
  Non-breaking thin space before %, :, ; ? and !
- **Currency.** G€ / M€ / G CHF / M$ rather than bn and m.
- **Citations are never translated.** Paper titles, journal names, book titles and
  author names stay exactly as published. Reference lists are copied verbatim.
- **Inline citation numbers** `(14)` and **tier markers** `[A] [B] [C] [D]` are
  structural. They must survive translation unchanged and still point at the same
  entries.
- **Quotations from English sources** are translated in the body, with the original
  English kept in parentheses where the exact wording carries the argument — for
  example a phrase from a technical paper that the critique turns on.
- **Register.** Formal, academic, impersonal. No regionalisms; this must read
  equally well in Montréal, Geneva and Paris.
- **Markdown structure** — headings, tables, YAML keys — is preserved exactly.
  Only the YAML `title`, `subtitle` and `status` values are translated.
